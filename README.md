# Schwarzfahrer

Schwarzfahrer im CH ÖV

Dieses Projekt ist eine Arbeit im ZHAW-Modul Python Scripting. Wir werten Daten zu Schwarzfahrten im Schweizer öffentlichen Verkehr aus.

## Idee

Als Datenbasis dienen von PostAuto erfasste Schwarzfahrer. Diese Fälle ordnen wir verschiedenen Zug- und Busverbindungen zu und berechnen darauf Statistiken. So wollen wir sehen, auf welchen Linien, Strecken und zu welchen Zeiten Schwarzfahren besonders häufig vorkommt.

## Vorgehen

1. **Daten einlesen:** Die PostAuto-Daten laden und bereinigen.
2. **Mapping:** Die erfassten Fälle auf Zug- und Busverbindungen abbilden.
3. **Auswertung:** Statistiken pro Verbindung, Linie, Zeitraum und weitere Kriterien berechnen.
4. **Darstellung:** Die Ergebnisse als Tabellen und Grafiken aufbereiten.
